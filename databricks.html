🧱 Práctica Databricks

Mismo tipo de ejercicio que el simulacro (persona.data), pero con otros datos para practicar.

Enunciado

En el Catalog de Databricks realiza:

  1. Crear el esquema practica
  2. Crear el volumen unidad_v
  3. Crear un directorio llamado datos
  4. Subir el archivo ventas.data en el directorio datos

En un notebook:

  1. Mostrar el contenido del archivo (usa %fs head)
  2. Crear un DataFrame de Spark con read.csv llamado dfVentas
  3. Mostrar el resultado con display()
  4. Crear una visualización y explicar su uso
  5. Crear la tabla tb_ventas en el esquema practica
  6. Consultar tb_ventas con una función de agrupamiento (count, sum, avg…)
⬇️ Descargar ventas.data
⚠️ Ojo: este archivo usa punto y coma ( ; ) como separador, no la barra | del simulacro. Columnas:
ID_VENTA;PRODUCTO;CATEGORIA;PRECIO;CANTIDAD;FECHA_VENTA;CIUDAD;ID_VENDEDOR

Intenta cada paso y luego toca "Ver solución".

1
Crear el esquema practica

Con la interfaz: menú izquierdo Catalog → workspace → botón Create → Create schema → nombre practica → Create.

O con SQL en una celda:

%sql
CREATE SCHEMA IF NOT EXISTS workspace.practica;
2
Crear el volumen unidad_v

Interfaz: Catalog → workspace → practica → Create → Volume → nombre unidad_v → tipo Managed → Create.

%sql
CREATE VOLUME IF NOT EXISTS workspace.practica.unidad_v;

Un volumen es el espacio del Unity Catalog para guardar archivos (no tablas): CSV, imágenes, .data, etc.

3
Crear el directorio datos

Interfaz: abre el volumen unidad_v → botón Create directory → datos.

dbutils.fs.mkdirs("/Volumes/workspace/practica/unidad_v/datos")
4
Subir ventas.data a datos

Entra a la carpeta datos → Upload to this volume → arrastra ventas.data → Upload.

La ruta final queda:

/Volumes/workspace/practica/unidad_v/datos/ventas.data

Formato de ruta: /Volumes/<catálogo>/<esquema>/<volumen>/<carpeta>/<archivo>

📸 Evidencia: captura del árbol del Catalog mostrando practica → unidad_v → datos → ventas.data.

5
Mostrar el contenido con %fs head 
%fs head /Volumes/workspace/practica/unidad_v/datos/ventas.data

%fs head muestra los primeros bytes del archivo en texto plano. Sirve para ver cómo viene el archivo (si tiene encabezado y qué separador usa) antes de leerlo con Spark.

6
Crear el DataFrame dfVentas con read.csv 
dfVentas = spark.read.csv(
    "/Volumes/workspace/practica/unidad_v/datos/ventas.data",
    header=True,
    inferSchema=True,
    sep=";"
)
ParámetroPara qué
header=TrueLa 1ª fila son los nombres de columnas
inferSchema=TrueDetecta tipos (int, double, date) en vez de todo string
sep=";"Separador del archivo (en el simulacro era "|")

Esquema esperado: ID_VENTA int, PRODUCTO string, CATEGORIA string, PRECIO double, CANTIDAD int, FECHA_VENTA date, CIUDAD string, ID_VENDEDOR int.

7
Mostrar con display() 
display(dfVentas)

display() muestra el DataFrame como tabla interactiva (ordenar, filtrar, descargar y crear gráficos). dfVentas.show() también funciona, pero solo imprime texto.

8
Crear una visualización y explicar su uso

En la salida de display(dfVentas): botón ＋ → Visualization → tipo Bar.

  • Eje X: CATEGORIA
  • Eje Y: CANTIDAD con agregación Sum
  • Nombre: Unidades vendidas por categoría → Save.

Explicación para el Word: "Esta visualización se usa para comparar el total de unidades vendidas por categoría de producto; permite identificar rápidamente qué categoría tiene mayor demanda."

Otras opciones válidas: promedio de PRECIO por CIUDAD (Bar, Avg), ventas por FECHA_VENTA (Line), proporción por CATEGORIA (Pie, Count).

9
Crear la tabla tb_ventas en el esquema practica 
dfVentas.write.mode("overwrite").saveAsTable("workspace.practica.tb_ventas")

saveAsTable guarda el DataFrame como tabla Delta administrada en el catálogo. mode("overwrite") evita error si ya existe. Verifica en Catalog → practica → Tables → tb_ventas.

Alternativa en SQL:

dfVentas.createOrReplaceTempView("v_ventas")
%sql
CREATE TABLE workspace.practica.tb_ventas AS
SELECT * FROM v_ventas;
10
Consulta con función de agrupamiento 
%sql
USE workspace.practica;

SELECT CATEGORIA,
       COUNT(ID_VENTA)              AS total_ventas,
       SUM(CANTIDAD)                AS unidades,
       ROUND(SUM(PRECIO*CANTIDAD),2) AS monto_total,
       ROUND(AVG(PRECIO),2)          AS precio_promedio
FROM tb_ventas
GROUP BY CATEGORIA
ORDER BY monto_total DESC;

Otras consultas cortas que también cumplen:

%sql
SELECT CIUDAD, COUNT(*) AS total_ventas
FROM workspace.practica.tb_ventas
GROUP BY CIUDAD ORDER BY total_ventas DESC;
%sql
SELECT ID_VENDEDOR, SUM(PRECIO*CANTIDAD) AS vendido
FROM workspace.practica.tb_ventas
GROUP BY ID_VENDEDOR ORDER BY vendido DESC;

Regla: toda columna del SELECT que no esté dentro de COUNT/SUM/AVG/MAX/MIN debe ir en el GROUP BY.

📄 Evidencias para el Word

  1. Captura del Catalog: esquema → volumen → carpeta → archivo.
  2. Celda %fs head con su salida.
  3. Celda read.csv mostrando el esquema del DataFrame.
  4. display() con la tabla.
  5. Gráfico + 1 línea explicando su uso.
  6. Celda saveAsTable + tabla visible en el Catalog.
  7. Consulta GROUP BY con su resultado.

Simulacro: persona.data

Esquema simulacro, volumen unidad_h, carpeta archivos, separador |.

%sql
CREATE SCHEMA IF NOT EXISTS workspace.simulacro;
CREATE VOLUME IF NOT EXISTS workspace.simulacro.unidad_h;
dbutils.fs.mkdirs("/Volumes/workspace/simulacro/unidad_h/archivos")

(Subir persona.data con "Upload to this volume".)

%fs head /Volumes/workspace/simulacro/unidad_h/archivos/persona.data
dfPersona = spark.read.csv("/Volumes/workspace/simulacro/unidad_h/archivos/persona.data",
                           header=True, inferSchema=True, sep="|")
display(dfPersona)

Visualización: Bar · X = ID_EMPRESA · Y = SALARIO (Average).
"Se usa para ver el salario promedio de los empleados por empresa."

dfPersona.write.mode("overwrite").saveAsTable("workspace.simulacro.tb_personas")
%sql
USE simulacro;
SELECT ID_EMPRESA, COUNT(ID) AS total_Empleados
FROM tb_personas
GROUP BY ID_EMPRESA
ORDER BY ID_EMPRESA ASC;

🔁 Plantilla para cualquier variante

Si en el examen cambian nombres, solo reemplaza las partes en <…>:

%sql
CREATE SCHEMA IF NOT EXISTS workspace.<esquema>;
CREATE VOLUME IF NOT EXISTS workspace.<esquema>.<volumen>;
dbutils.fs.mkdirs("/Volumes/workspace/<esquema>/<volumen>/<carpeta>")
%fs head /Volumes/workspace/<esquema>/<volumen>/<carpeta>/<archivo>
df<Nombre> = spark.read.csv("/Volumes/workspace/<esquema>/<volumen>/<carpeta>/<archivo>",
                           header=True, inferSchema=True, sep="<separador>")
display(df<Nombre>)
df<Nombre>.write.mode("overwrite").saveAsTable("workspace.<esquema>.<tabla>")
%sql
SELECT <columna>, COUNT(*) AS total
FROM workspace.<esquema>.<tabla>
GROUP BY <columna>;
Primero mira la salida de %fs head para saber el separador: |, ;, , o tabulación \t.
